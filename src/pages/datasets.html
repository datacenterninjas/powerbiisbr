Practice datasets

Five business scenarios, each as a clean version and a deliberately messy version (~100 rows, real column headers). Download and open directly in Excel, or load straight into Power BI via Get Data → Text/CSV.

DatasetColumnsCleanDirty (for Power Query practice)

Retail
multi-store chain		 Store, City, State, Product, Sales, Profit, Inventory, Date ⇩ CSV ⇩ CSV
Banking
loan portfolio		 Customer, Loan Amount, EMI, Income, Credit Score, Loan Status ⇩ CSV ⇩ CSV
Hospital
patient records		 Patient, Doctor, Department, Age, Gender, Diagnosis, Bill Amount, Admission Date, Discharge Date ⇩ CSV ⇩ CSV
Tip: Right after loading any file into Power BI, rename the table (right-click in the Fields pane → Rename) to match the dataset name above — Sales, HR, Retail, Banking, Hospital. Every DAX formula on this site assumes those exact names.
