Time intelligence — the same measure, a different time window

YTD (Year-to-Date), MTD (Month-to-Date), and QTD (Quarter-to-Date) all answer the same shape of question: "total so far, within the current period" — without hand-typing a date range that goes stale the moment the calendar turns over.

Sales YTD = TOTALYTD(SUM(Sales[Sales]), Sales[Date])
Why this needs a real Date table: Time intelligence functions rely on a proper, continuous Date column marked as a Date table in the model — the same "Date column typed as text sorts wrong" trap already covered on the Power Query and Visualizations pages resurfaces here, with higher stakes.
