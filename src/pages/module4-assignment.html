A different file, the same discipline, nobody walking you through it this time

The Dirty → Clean Walkthrough cleaned Banking_Dirty.csv for you, step by step. This assignment is the same job, on a messier file, with no walkthrough — Sales_Dirty.csv, 100 rows, and at least nine distinct problems nobody is going to point out for you this time.

Worth 10 marks. Individual submission, through the LMS portal. Download Sales_Dirty.csv from the Datasets page and find its problems the same way the walkthrough did: open the raw CSV first, before touching Power Query.

The brief

Clean Sales_Dirty.csv completely in Power Query, entirely through the graphical interface — no hand-editing the CSV in Excel first, and no manually retyping values in Power BI. Every fix has to be a reproducible query step, because that's the actual point of Power Query: run it again next month on a new export and it cleans itself the same way, automatically.

What will cost you marks: opening the CSV in Excel, fixing a few cells by hand, re-saving it, and loading the "clean" version into Power BI. That produces a clean-looking file but zero reproducible steps — it has to be redone by hand every single month. Grading checks the Applied Steps pane, not just the final numbers.

Deliverable checklist

  • ✓
    All exact duplicate rows removed
  • ✓
