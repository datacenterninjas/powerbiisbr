Module 2 · Filters

Same filter, three different reaches.

A restricts which rows are included — the only real decision is how FAR that restriction should reach: one visual, one page, or the whole report.

The three scopes

Visual-level filter

Affects: one specific visual only.

When to use: one chart needs to show something different from everything else on the page — e.g. a "Top 5 Products" table that should stay Top 5 even while the rest of the page shows all products.

Example: A Filters pane filter applied with that one visual selected.

Page-level filter

Affects: every visual on the current page.

When to use: the whole page is about one slice of the business — a "2025 Only" page, or a page dedicated to one region.

Example: Set once at the Page level in the Filters pane; every visual added to that page inherits it automatically.

Report-level filter

Affects: every visual on every page of the report.

When to use: a restriction that should never be bypassed anywhere — e.g. excluding test/dummy data, or scoping an entire report to one business unit.

Example: Set at the Report level in the Filters pane — the broadest, least common scope.

The rule of reach: Visual filter → one visual. Page filter → every visual on that page (including ones added later). Report filter → every visual on every page (including pages added later). Higher scopes are inherited automatically — a page filter doesn't need to be repeated per visual.

Common mistakes

Wrong scope, right value

Setting a filter at Report level "to be safe" when only one visual needed it — now every future page inherits a restriction nobody remembers adding.

Forgetting inherited filters exist

A number looks wrong on one visual, but the real culprit is a Page or Report filter set weeks ago, not the visual itself — always check all three panes (Visual, Page, Report) in the Filters pane before debugging the DAX.

Best practice: Default to the narrowest scope that solves the problem. It's much easier to notice and widen a Visual filter later than to hunt down a forgotten Report filter across a dozen pages.
