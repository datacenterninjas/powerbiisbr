Module 5 · Assignment

Take it off your laptop — the step every other assignment skipped

Every assignment so far ended in a .pbix file nobody but you could open. This one doesn't count until it's live in the Power BI Service, shared the way a real workspace actually gets shared.

Worth 10 marks. Individual submission, through the LMS portal. Reuse any report you've already built this course — Module 2's assignment or the Final Project both work well — this assignment is about what happens to it after Desktop, not about building something new.
Account note: a free Power BI account publishes to your own My Workspace with no cost — enough for Tasks 1, 2, and 4. Task 3 (sharing to another person) needs either a Pro license or a Premium-capacity workspace, which your institution may or may not provide. If sharing genuinely isn't available on your account, screenshot the attempt and the message Power BI gives you instead — that's still evidence you know where the feature lives, which is what's actually being graded.

The four tasks

#Task
1Publish a report from Desktop to a workspace in the Service (Home ribbon → Publish). Not "My Workspace" by default if you can help it — create a small named workspace first, so you practice the step a real team project would need.
2From the published report, pin at least 2 visuals to build a Dashboard — a single-page pinboard, distinct from the multi-page Report it was pinned from.
3Share the report (Share button → add a person by email, or generate a link) — or, if your account can't share, screenshot the attempt per the account note above.
4Open the dataset's Settings → Scheduled refresh screen and either configure a refresh schedule (if your data source supports it from the cloud) or screenshot the screen and explain in one sentence why this dataset can't be scheduled from where it's hosted (e.g. a local file with no gateway).

Short-answer questions (answer in the PDF, 2–3 sentences each)

  1. You want a teammate to help build the report further, and a manager to only ever view it, never edit it. Which two different workspace roles do you give them, and why does the distinction matter?
  2. Your report was built with Import mode. Explain in your own words why it needs a Scheduled Refresh at all, when a Live Connection or DirectQuery report wouldn't.
  3. Your manager asks for "the dashboard," and hands you a report file. Politely, what's actually wrong with that sentence, and what would you build instead if they truly wanted a Dashboard?
