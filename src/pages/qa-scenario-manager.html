Ask the report a question instead of building a chart for it

Two features for exploring "what if" without leaving the report: asking in plain English, and testing a hypothetical number interactively.

This page is a placeholder — full lesson content lands here as the class reaches this module. The framing below is real; the guided walkthrough is still to come.

Q&A — natural language queries

The Q&A visual lets a report viewer type a question in plain English — "total sales by region last year" — and Power BI builds a visual on the fly to answer it, using the field names already in the model. It's genuinely useful for quick ad-hoc exploration, and genuinely dependent on well-named fields: a column called Sales[Sales] answers "total sales" far better than one still called Sales[Col_7], which is exactly why the Power Query page's Rename Columns lesson matters beyond just tidiness.

Setup matters: Q&A quality improves a lot from adding synonyms in the model (e.g. teaching it "revenue" also means the Sales column) — this module will cover that setup, not just the typing-a-question part.

A note on "Scenario Manager"

Scenario Manager itself is an Excel what-if-analysis feature, not a native part of Power BI. Power BI's closest equivalent is a What-if parameter — a slider a report viewer can drag (e.g. "Discount %") that live-recalculates a DAX measure using the slider's current value, giving the same "test a hypothetical" feel inside a Power BI report.

Adjusted Sales = SUM(Sales[Sales]) * (1 - 'Discount % Parameter'[Discount % Value])
