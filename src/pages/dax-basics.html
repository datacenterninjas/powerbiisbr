Calculated Column vs. Measure — the first fork in the road

Computed once, row by row, and physically stored in the table — like adding a new column in Excel with a formula dragged down every row.

Example: Full Name = [First Name] & " " & [Last Name] — one fixed value per row, doesn't change based on what's filtered on screen.

Computed on the fly, only when a visual asks for it — recalculates instantly based on whatever's currently filtered/sliced.

Example: Total Sales = SUM(Sales[Sales]) — the same measure returns a different number for "2025" than for "2024," automatically.

The rule of thumb this module will build toward: if the number should change when someone clicks a slicer, it's almost always a measure, not a calculated column.
