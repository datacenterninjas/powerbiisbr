Golden rule

Always click Transform Data, never Load, unless you've already verified the data is clean.

DIVIDE, not /

DIVIDE() safely handles divide-by-zero. CALCULATE() filters a sum/count by a condition.

DAX formulas from this course

Average Order Value = DIVIDE(SUM(Sales[Sales]), DISTINCTCOUNT(Sales[Order ID])) Profit Margin % = DIVIDE(SUM(Sales[Profit]), SUM(Sales[Sales])) Length of Stay = DATEDIFF(Hospital[Admission Date], Hospital[Discharge Date], DAY) Average Salary = AVERAGE(HR[Salary]) Total Loans = COUNTROWS(Banking) Approved Loans = CALCULATE(COUNTROWS(Banking), Banking[Loan Status] = "Approved") Approval Rate = DIVIDE([Approved Loans], [Total Loans])

10 most common beginner mistakes

  1. Clicking Load instead of Transform Data out of Excel habit
  2. Leaving default chart titles like "Sum of Sales by Category"
  3. Using a Pie Chart with 8+ slices
  4. Forgetting to Trim text columns, silently splitting one customer into two
  5. Summing a column that should be averaged (Salary, Credit Score)
  6. Ignoring outliers instead of investigating them
  7. Using a Bar Chart for a trend over time (should be a Line Chart)
  8. Overloading one page with every chart type "just because you learned it"
  9. Not checking Data Types before building a chart
  10. Skipping Remove Duplicates, quietly inflating every total
