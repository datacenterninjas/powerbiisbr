Five measures, each one number harder than the last

DAX is a skill you build by writing formulas that break, then fixing them — not by reading about them. All five measures below use only functions this module covers: SUM, DIVIDE, TOTALYTD, CALCULATE, and SAMEPERIODLASTYEAR.

Worth 10 marks. Individual submission, through the LMS portal. Built on AdventureWorksDW, same database as every module so far.

Before you write a single measure

Mark DimDate as a Date Table first. TOTALYTD and SAMEPERIODLASTYEAR (Tasks 3 and 5) silently assume this — without it they either error or quietly return wrong numbers. In Model view: select DimDate → Table tools ribbon → Mark as Date Table → point it at DimDate[FullDateAlternateKey]. Confirm a relationship line already connects FactInternetSales[OrderDateKey] to DimDate[DateKey] — if it's missing, create it in Model view before continuing.

The five measures

#MeasureBusiness question it answers
1A plain aggregation: Total Sales, summing FactInternetSales[SalesAmount]"How much have we sold, total?"
2A ratio using DIVIDE: Profit Margin %, from SalesAmount and TotalProductCost"Of every rupee of sales, how much is actually profit?"
3A time-intelligence measure using TOTALYTD: Sales YTD"How are we doing so far this year?"
4A CALCULATE + column-filter measure: Road Bike Sales, filtered to DimProduct[ProductLine] = "R""How much of our total is from Road bikes specifically, regardless of what's sliced on screen?"
5A CALCULATE + SAMEPERIODLASTYEAR measure: Sales Same Period Last Year"Is this actually growth, or does last year look the same?"

What actually gets graded

For every measure, submit two things, not one: the formula itself, and a single plain-English sentence explaining what its is doing at the moment it calculates. That sentence is the actual MBA-level skill here — anyone can copy a DIVIDE formula off a table; explaining why Measure 4 ignores whatever Category slicer is on the page, in your own words, is what the marks are for.

Example of the explanation we want (this one won't earn marks — it's for Measure 4, already given away above): "Road Bike Sales always filters to ProductLine = R first, then sums SalesAmount within that — so it shows the same number whether or not a viewer has clicked a different ProductLine in a slicer elsewhere on the page." Five sentences like that, one per measure, are worth as much as the formulas themselves.
