Module 1 · Assignment

Your first graded dashboard — built on data you picked yourself

Everything through Basic Visualizations, applied to a real public dataset instead of a practice file — pick a dataset from Kaggle, build it, export it, submit it.

Worth 10 marks. Individual submission, through the LMS portal. Uses only what Module 1 has taught so far — no DAX, no Power Query deep-cleaning required, no Module 2+ features expected.

The brief

Pick any dataset from Kaggle that has at least one text/category column and two or three numeric columns — download it, load it into Power BI, and build a small one-page dashboard using the chart types from this module.

Suggested datasets (if you don't already have one in mind)

DatasetWhy it worksTry visualizing
Titanic — Machine Learning from DisasterSmall, clean, famous — categories (Class, Sex, Embarked) and numbers (Age, Fare) side by sideSurvival rate by Class (Bar), Passenger split by Sex (Pie), Age vs Fare (Scatter)
Netflix Movies and TV ShowsRich category data — Country, Genre, Type, Release YearTitles by Genre (Bar), Movies vs TV Shows (Pie), Titles added per Year (Line)
World Happiness ReportOne row per country, several comparable numeric scoresHappiness Score by Country (Map), GDP vs Happiness (Scatter), Top 10 Countries (Bar)
IPL Complete DatasetFamiliar if you follow cricket — teams, venues, seasons, scoresMatches Won by Team (Bar), Matches by Venue (Tree Map), Runs by Season (Line)
Video Game SalesLarge, well-known, easy KPI storyTotal Sales (KPI Card), Sales by Platform (Bar), Sales by Genre (Pie)

Any dataset works as long as it has the shape described in the brief above — these five are just a safe starting point if you're not sure where to look.

Deliverable checklist

  • ✓
    Data imported into Power BI Desktop from your chosen Kaggle file (CSV or Excel)
  • ✓
    At least 1 KPI Card showing one headline number
  • ✓
    At least 1 Bar or Pie Chart comparing a category
  • ✓
    At least 1 Line Chart, Scatter Plot, Map, or Tree Map — whichever fits your data best
  • ✓
    Real chart titles — no default "Sum of X by Y" left on screen
  • ✓
    One consistent Theme applied across the whole page

How to submit

Two files, exact naming, both to the LMS portal:
  1. Your Power BI file, saved and submitted as YourFullName.pbix — e.g. Anjali_Kumar.pbix
  2. A single PDF containing a full-page screenshot of every visual you built, submitted as YourFullName_Screenshots.pdf

Turning screenshots into one PDF: capture each visual (Windows: Win + Shift + S · Mac: Cmd + Shift + 4), paste each one onto its own slide in PowerPoint or page in Word, then File → Export → Create PDF. One PDF, one screenshot per visual, in the order they appear on your dashboard page.
