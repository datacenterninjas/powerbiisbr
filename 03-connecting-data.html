Getting your data into Power BI — three ways

Excel, a company database, or a public website — the click-path is almost identical every time: Get Data → pick a source → Navigator → Transform Data.

Connecting to Excel

Home→Get Data→Excel Workbook→select file→Navigator (tick sheet)→Transform Data
OptionWhat it doesWhen to use
LoadBrings data in exactly as-is, no cleaning.Only when you're 100% sure the data is already clean — rare in real life.
Transform DataOpens Power Query first so you can clean before it touches your report.your default click, always
CombineStacks multiple files/sheets with the same structure into one table.Your company saves one Excel file per month and you want all 12 as one table.
Golden rule: Always click Transform Data, never Load, unless you've already inspected the data and know it's clean.

Connecting to SQL Server

A SQL Server is a very large, very organized Excel workbook that lives on a powerful shared computer instead of your laptop — it can hold billions of rows, many people can use it at once, and it's always "live."

Server Name

The address of the machine where the database lives, e.g. salesdb.company.com. Like a building address.

Database Name

The specific database on that server, e.g. SalesDB. One server can host many databases — like flats in a building.

Authentication

Windows Authentication (your company login, automatic) or Database Authentication (a separate username/password).

Connection String

Server + database + settings bundled into one line, e.g. Server=salesdb.company.com;Database=SalesDB;

Import vs. DirectQuery vs. Live Connection

Full comparison is on the Architecture page — the short version: use Import for this entire course and for almost everything you'll do as a beginner.

Connecting to Web Data

Home→Get Data→Web→paste URL→OK→Navigator→Transform Data

Works on any public page with an HTML table — Wikipedia country/state data tables, government open-data portals (data.gov.in), public COVID dashboards, weather data. Power BI scans the page and lists every table it finds as Table 0, Table 1… — preview each one before loading to make sure you picked the right one.

Real limitation: if the website changes its table layout later, the connection can break. This is a genuine trade-off of web scraping, not a bug in Power BI.
