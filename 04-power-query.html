04 · Power Query

Real data is never clean. This is where you fix it.

Some analysts spend 70–80% of their time right here, not in charts. Every fix below is demonstrated on our actual practice file, Sales_Dirty.xlsx — download it from the Datasets page and follow along.

TransformationFixesWhere to click
Rename ColumnsCryptic headers like col_7Double-click the column header
Remove ColumnsUnused clutter columnsRight-click header → Remove
Split ColumnOne column secretly holding two values ("Bangalore, Karnataka")Select column → Split Column → By Delimiter
Merge ColumnsTwo columns that need to become one (First + Last Name)Select both → right-click → Merge Columns
Change Data TypeWrong type blocking math or chronological sortingClick the type icon on the column header
Remove DuplicatesRepeated rows quietly inflating totalsRight-click column(s) → Remove Duplicates
Replace ValuesKnown typos, inconsistent labelsRight-click column → Replace Values
TrimLeading/trailing spaces — makes "Rohit" ≠ " Rohit "Transform → Format → Trim
CleanInvisible/non-printable charactersTransform → Format → Clean
Fill Down / UpBlanks left by merged-cell Excel exportsTransform → Fill → Down/Up
Null HandlingBlank or "NULL"-text cells breaking SUM/AVERAGEReplace Values (with a default) or Remove Rows

See it on real (messy) data

These are genuine rows from the practice dataset — not made-up examples. Each "before" is exactly what you'll see when you open Sales_Dirty.xlsx.

Never guess a fake number to hide a blank. Either fill it with a defensible business default, or remove the row — and always be ready to explain which choice you made and why.
