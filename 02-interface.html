02 · The Interface

Six zones. Once you can name them, you can navigate them.

Power BI Desktop looks intimidating for about twenty minutes. Every screen you'll ever see is built from the same six zones below — learn the map once.

ZonePurposeWhen you use it
① Ribbon
Home · Insert · Modeling · View		Home = Get Data, Refresh, Publish. Insert = logos, text, buttons. Modeling = relationships & DAX measures.Home starts every session; Modeling whenever tables need linking or a calculation is needed.
② Report CanvasThe blank page where visuals are placed and arranged.Every time you design what the dashboard looks like.
③ Visualizations PaneThe palette of chart types — bar, pie, line, map, and 30+ others.Anytime you want to add a new chart.
④ Fields PaneEvery table and column available — your ingredient list.Constantly — you drag from here onto every chart you build.
⑤ Filters PaneRestricts what data shows, on one visual, the page, or the whole report — without deleting anything.To focus a view, e.g. "2025 only" or "exclude cancelled orders."
⑥ Page NavigationTabs at the bottom to switch between report pages, plus the Report / Data / Model view switcher.Multi-page dashboards; switching to Data View to sanity-check a column, or Model View to check relationships.
Common mix-up: Model View is only for relationships — it is not where you build charts. That's Report View. Students confuse these two constantly in week one.
