"Pivot tables in Power BI" — a translation, not a new feature

Power BI doesn't have a visual literally called "Pivot Table" or "Pivot Chart." The equivalent already taught on this site is the Matrix visual — rows, columns, and values wells, exactly like an Excel PivotTable — paired with any chart type as its "Pivot Chart" counterpart, since every Power BI chart already re-aggregates live as filters/slicers change, which is the entire point of a PivotChart in Excel.

If Excel PivotTables are already familiar, the Matrix visual (Module 2) will feel less like a new tool and more like the same idea with a different toolbar.
